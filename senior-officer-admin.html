Integration Guide

Add the "Talk to a Senior Officer" widget to every page by pasting this line before </body>:

<script src="senior-officer-chat.js"></script>

The widget auto-loads your API key, provider choice, and knowledge base from Firestore on every page load. Changes made here are live immediately — no redeployment needed.
